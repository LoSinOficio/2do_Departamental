## 1. Descripción general

Este repositorio contiene las prácticas desarrolladas para el segundo departamental de la asignatura Abstracción y Uso de Datos. El enfoque principal está en el manejo de algoritmos de ordenamiento y en la implementación de estructuras de datos, tanto de forma estática como dinámica.

Las actividades se realizan en C++ y están organizadas en archivos independientes, cada uno con su propia lógica y función principal (`main`). Esto permite compilar y ejecutar cada práctica por separado según el requerimiento del ejercicio.

## 2. Objetivo

Aplicar los conceptos del segundo departamental mediante la resolución de ejercicios relacionados con:

- Ordenamiento de caracteres, enteros y tipos de dato definidos por el usuario.
- Ordenamiento por burbuja, merge sort y quick sort.
- Ordenamiento indirecto mediante punteros o índices.
- Manejo de punteros para estructuras de datos.
- Implementación de pilas, colas y listas.
- Uso de bibliotecas estándar de C++ para estructuras de datos.

## 5. Compilación y ejecución

Se necesita un compilador compatible con C++11 o superior, como `g++`.

### Ejemplo de compilación

```bash
g++ -std=c++11 "Practica 16.cpp" -o practica16
```

### Ejecución en Windows

```powershell
.\practica16.exe
```

### Ejecución en Linux o macOS

```bash
./practica16
```

Cada práctica debe compilarse por separado porque cada archivo contiene su función `main` propia.

## 6. Conclusión

El segundo departamental comprende dos grandes bloques: algoritmos de ordenamiento y estructuras de datos. A través de estas prácticas, se reforzaron conceptos como la lógica de clasificación, el uso de punteros, la organización de datos en memoria y la implementación de estructuras dinámicas y estáticas.

Este trabajo permitió comprender cómo los datos pueden organizarse, manipularse y accederse de manera eficiente mediante distintas técnicas de programación en C++.
